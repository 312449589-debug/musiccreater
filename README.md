# musiccreater · 弦伴

AI 音乐创作产品的新项目。长期愿景：陪你写出并弹会第一首自己的歌。

## 本版范围

- 音乐生成：提示词、标签、简短问题与指定时长。
- 保存作品：命名、保存、再次试听与下载。
- 分享作品：用户主动下载分享或发布到作品广场。

本版不包含个性化歌曲推荐、逐步完善 Demo 和成长报告，也不扩展版本工作台、练习计划或自动评分。
